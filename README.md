# Digitalizing Genco O&M — Paper 1

GT & ST Community · Day 1 · Paper 1 · Presenter: TED-DD

Practical use cases and insights from two in-house systems:

- **SJSAS Smart Plant** (Manjung): one portal for daily performance, reliability, fuel advisors and the ADAbot assistant.
- **JEP Boiler Anomaly Detection** (Jimah East, Units 10 & 20): a 3-layer model on ~141 PI tags that flags combustion anomalies and explains them.

## Install as an app (tablet / phone)

Live at **https://adzimaziz.github.io/turbinecomm/** (GitHub Pages).

1. Open the link in **Chrome** (Android) or **Samsung Internet** and enter the PIN once.
2. Chrome: **⋮ → Install app** (or **Add to Home screen**). Samsung Internet: **≡ → Add page to → Home screen**. iPhone / iPad: Safari **Share → Add to Home Screen**.
3. The **Paper 1** icon opens the deck fullscreen in landscape. After the first open, everything is cached, so it **works with no internet**.

Updating the deck: rebuild `index.html` and `sw.js` together (the service-worker cache name follows the deck), push, then open the app once while online to pick up the new version.

## Presenting

Open `index.html` in Chrome or Samsung Internet (laptop, tablet or phone), enter the 4-digit PIN, and tap **⛶** for fullscreen. It is designed for a 16:10 landscape screen. The PIN is asked once per browser tab session.

| Action | Touch | Keyboard |
|---|---|---|
| Next / previous slide | swipe, or tap right / left edge | → / ←, Space, PageDown / PageUp |
| All slides | tap the slide counter | O |
| Speaker notes (with timing) | **N** button | N |
| Day / night mode | ☀ / ☾ button | T |
| Fullscreen | ⛶ button | F |
| ADAbot on / off | red dot | A |

- **3D plant** (title slide and slide 4): drag to rotate, tilt the tablet (gyroscope), double-tap the slide 4 model to reset.
- **ADAbot laser**: with ADAbot out, tap a card, bullet, chip or 3D label to spotlight it; tap empty space or press Esc to clear.
- **Slide 6 examples**: tap the L1 / L2 / L3 card (or **▶ See example**) for an illustrative chart.

Example charts and chat exchanges in the deck are illustrative, not real plant data.
